# Jae-s-LIB

A lightweight Roblox UI library written in Luau based on Orion Lib

Jae-s-LIB provides a simple API for building interactive interfaces with windows, tabs, buttons, toggles, sliders, dropdowns, keybinds, textboxes, color pickers, notifications, themes, and configuration persistence

## Features

- Customizable windows
- Tabs and sections
- Buttons
- Toggles
- Sliders
- Dropdowns
- Keybinds
- Textboxes
- Color pickers
- Labels and paragraphs
- Notifications
- Built-in themes
- Custom themes
- Runtime theme switching
- Background images
- Configuration saving/loading
- Window dragging and resizing
- Automatic connection cleanup
- Lucide icon support
